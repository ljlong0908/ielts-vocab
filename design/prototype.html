页面直达（原型每处可点，底部按钮能走通全流程）
全交互：每个按钮都有响应，无死点。学习页 6 个词逐词推进（含"暂缺 / 生成中"两个边界态），练习页四态可玩，打卡后首页进度自动补满。
完整流程：引导 → 首页 → 学习 → 练习 → 打卡 → 回首页
onboarding → index → learn → practice → checkin → index
index ⇄ stats / wrongbook / profile（tab 互跳）
热区自检：点「显示热区」→ 蓝框=可点区域，红框=小于 44px 触控下限，标注实际像素尺寸。
单页速览：地址栏会实时反映当前页，如 #learn、#stats（不含 s- 前缀）。重载后停在原页；也可直接改锚点跳页。
⚠️ 图标：这里是内联 <svg>，wxml 不支持，落地须换 <image>（base64/云存储）或 iconfont。
⚠️ 文案风险：app.json 的 navigationBarTitleText 仍是「雅思词汇」，与本原型「雅词本」不一致，且「雅思」是他人在先商标。
